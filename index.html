Enterprise workloads we cover

Enterprise data protection extends across many workload types. BackupSteward assesses protection coverage, backup operations and recovery requirements across the technologies that support your business. Actual integration and protection capabilities depend on the backup product and environment.

Databases

Oracle Database, Microsoft SQL Server, SAP HANA, IBM Db2, PostgreSQL, MySQL and other enterprise database platforms. Review database protection, application consistency, transaction log handling and recovery requirements.

Enterprise Applications

SAP applications, Microsoft Exchange, Microsoft 365, SharePoint and other business-critical applications. Review application-aware protection, dependencies and recovery procedures.

Virtualisation Platforms

VMware vSphere, Microsoft Hyper-V and other virtualisation environments. Review VM protection, workload coverage, infrastructure dependencies and recovery options.

Physical Servers

Windows Server, Linux servers, bare-metal systems and standalone workloads. Review system protection, file-system backups and bare-metal recovery readiness.

File Services & NAS

Enterprise file servers, NAS appliances, network shares, unstructured data and large-scale file environments. Review file protection, retention, capacity and recovery granularity.

Cloud Workloads

Amazon Web Services, Microsoft Azure, Oracle Cloud Infrastructure and other cloud environments. Review cloud VM protection, storage, connectivity, data protection policies and recovery dependencies.

Containers & Kubernetes

Kubernetes clusters, containerised applications, persistent volumes and cloud-native environments. Review application data protection, configuration protection and recovery considerations.

Endpoints & User Data

Enterprise laptops, desktops, remote-user systems and business-critical endpoint data. Review endpoint protection coverage and recovery requirements.

Object & Unstructured Storage

Object storage, enterprise repositories and large-scale unstructured data. Review data protection, retention, versioning, immutability and recovery requirements.
